# LiDAR 측정 데이터 생성 프로그램 프로젝트 명세

## 목적과 개발 범위

LiDAR(Light Detection and Ranging) 측정 데이터 생성 프로그램은 설정으로 주입한 적재 공간과 센서 배치를 기준으로 각 센서가 관측할 각도, 거리와 품질 값을 생성한다. 적재와 수거에 따라 변하는 장면을 구성하고, 센서별 한 회전의 측정점 묶음인 스캔을 외부 데이터 변환 프로그램에 제공한다.

각 센서는 한 회전의 스캔을 확보하면 다른 센서를 기다리지 않고 독립적으로 전달한다. 스캔 경계는 고정 시간이나 고정 측정점 개수가 아닌 회전 완료를 기준으로 한다.

생성 경로와 실제 센서 수집 경로는 센서 기준 측정값을 입력받는 동일한 데이터 변환 기능에 연결된다. 생성 프로그램은 장면 구성과 측정 데이터 생산을 담당하고, 공간 좌표변환과 적재 상태 산출은 수신 프로그램이 담당한다.

제조사 센서 통신 프로토콜은 재현하지 않는다. 제조사 SDK(Software Development Kit) 처리 이후의 측정 의미를 공통 입력으로 제공한다.

## 범위 경계

| 포함 | 제외 |
| --- | --- |
| 적재과 수거 장면 시뮬레이션 | 실제 센서 네트워크 프로토콜 재현 |
| 센서별 회전 단위 스캔 생성 | 공간 좌표변환과 적재률 산출 |
| 거리 오차, 무효 측정과 수거 중 가림 표현 | 모니터링 서버의 저장과 UI(User Interface) 표시 |
| 재시도와 중복 처리 방지를 포함한 스캔 전송 | 현장 규격과 설치값의 코드 내장 |

## 개발 환경과 배포

| 항목 | 적용 기준 |
| --- | --- |
| 구현 언어 | Python 3.14 |
| 프로젝트와 의존성 관리 | uv |
| 배포 산출물 | OCI(Open Container Initiative) 컨테이너 이미지 |
| 실행 대상 | Linux ARM64 엣지 환경 |

환경 설정, 실행 설정, 수신 주소와 포트는 실행 시 제공한다. 생성 프로그램을 새로 시작하면 빈 적재 공간에서 새 실행을 시작한다. 연결 중단은 시나리오를 초기화하지 않고, 프로그램 재시작은 새 실행 식별자로 구분한다.

## 환경과 설치 설정

공통 환경 설정은 공간 형상, 기준 바닥, 센서 식별자와 설치 위치 및 방향을 포함한다. 생성 프로그램과 데이터 변환 프로그램은 동일한 내용의 환경 설정을 읽는다.

각 스캔은 적용한 설정의 식별자인 `environment_id`를 포함한다. 수신 프로그램은 스캔과 현재 설정의 식별자 일치 및 `sensor_id` 존재를 검사한다.

공통 환경 설정은 UTF-8 JSON(JavaScript Object Notation)으로 표현하며 다음 필드를 포함한다.

| 필드 | 의미 |
| --- | --- |
| `environment_id` | 비어 있지 않은 설정 식별자 |
| `length_unit` | 거리 단위 `m` |
| `angle_unit` | 각도 단위 `deg` |
| `boundary_xy_m` | 경계 순서에 따른 평면 꼭지점 배열 |
| `floor_z_m` | 바닥 Z 좌표 |
| `top_z_m` | 외벽 상단 Z 좌표 |
| `sensors` | 센서 설정 배열 |
| `sensors[].sensor_id` | 중복되지 않는 센서 식별자 |
| `sensors[].p0_m` | 센서 측정 중심의 `[x, y, z]` |
| `sensors[].u0` | 0도 방향의 3차원 단위벡터 |
| `sensors[].u90` | 90도 방향의 3차원 단위벡터 |

경계 다각형은 자기 교차가 없고 바닥보다 상단이 높아야 한다. 방향벡터는 길이가 1이고 서로 직교해야 한다. 정확한 현장 규격과 설치값은 공개 자료에 포함하지 않는다.

## 적재와 수거 시나리오

적재 표면은 투입 지점 부근이 높고 주변으로 퍼지는 큰 더미와 국소 요철로 구성한다. 투입과 수거는 기존 표면을 점진적으로 변형하며, 표면은 바닥과 외벽 상단 사이에 유지한다.

생성 프로그램은 센서별 광선과 스크랩 표면, 외벽 및 바닥의 최초 교차 위치에서 거리를 계산한다. 교차 대상이 없거나 유효 거리 범위 밖이면 무효 측정으로 처리한다.

평균 적재 시간, 회차별 적재 시간, 투입 속도 변동, 수거 임계치와 수거 속도는 실행 설정으로 조정한다. 수거 완료 시 전체 표면은 기준 바닥이 되고 다음 적재 회차를 시작한다.

## 센서 측정과 왜곡

각 측정점은 센서 기준 각도, 거리와 8비트 품질 값을 표현한다. 거리 0은 높이 0이 아닌 무효 거리 측정을 의미한다. 품질 값만으로 유효한 거리나 측정 대상을 판단하지 않는다.

생성 시나리오는 다음 왜곡을 기준 측정과 분리해 표현한다.

- 평상시 거리 오차와 무효 측정
- 낙하물에 의한 짧은 표면 왜곡
- 수거 장비 또는 들어 올린 스크랩에 의한 가림
- 센서 또는 연결 상태에 따른 지속적 무효 구간

오차를 적용하기 전의 표면과 기준 측정값을 검증 기준으로 유지한다. 왜곡의 비율과 분포는 실행 설정과 재현 가능한 무작위 시드로 제어한다.

## 스캔 전송 계약

스캔은 MessagePack 메시지로 전송하며 다음 식별 정보와 측정점 배열을 포함한다.

| 항목 | 의미 |
| --- | --- |
| `run_id` | 생성 프로그램 실행 식별자 |
| `sensor_id` | 센서 식별자 |
| `environment_id` | 환경과 설치 설정 식별자 |
| `scan_id` | 해당 실행과 센서 내의 스캔 식별자 |
| `captured_at` | 스캔의 대표 시각 |
| `points` | 각도, 거리와 품질 값의 배열 |

전송은 처리 완료 ACK(Acknowledgement)를 확인한다. 시간 초과나 연결 중단 시 상한이 있는 지수 증가 대기와 무작위 지연을 적용해 재시도한다. 수신 프로그램은 식별자로 중복 스캔을 구분하고 이미 처리한 스캔에 동일한 결과를 응답한다.

## 보안과 공개 범위

공개 코드와 컨테이너 이미지는 현장 규격, 센서 설치값, 사설 주소, 자격 증명과 실측 데이터를 포함하지 않는다. 공개용 설정 예시는 현장과 무관한 시험 환경을 사용한다.

## 완료 기준

- 동일한 설정과 무작위 시드에서 동일한 스캔 열을 재현한다.
- 빈 상태, 적재, 투입 전환, 수거와 수거 완료 시나리오를 검증한다.
- 센서별 회전 경계, 각도 순서, 거리 범위와 무효 측정 표현을 검증한다.
- 오차가 없는 기준값과 왜곡을 적용한 결과를 독립적으로 검증한다.
- 전송 중단, 재시도, 중복 수신과 설정 불일치를 검증한다.
- Linux ARM64 대상에서 이미지를 빌드하고 지속 생성 부하를 검증한다.
