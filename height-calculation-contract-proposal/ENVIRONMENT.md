# 공개 합성 환경 전제

## 규격의 성격

환경 전제는 좌표계, 적재 공간, 센서 배치와 scan 교차 규칙의 4개 요소로 구성된다. 이 수치는 실제 현장 측정이나 RPLIDAR S2E 하드웨어 사양에서 계산한 값이 아니다. 프로젝트가 생성기, 높이 계산 프로세스와 시각화 프로그램의 공통 검증 기준으로 정한 공개 합성 규격이다.

Source Repository의 `examples/environment.v1.json`이 환경 규격의 정본이다. 이 묶음의 `v1/fixtures/environment.v1.json`은 별도 Repository에 그대로 전달하기 위한 동일 내용의 배포 사본이다. Producer 자동 검증은 두 JSON 문서가 동일한지 확인한다.

## 좌표계

모든 위치와 거리는 meter 단위의 직교 좌표를 사용한다. x축과 y축은 수평 평면이고 z축은 위쪽이다. x축과 y축은 실제 방위나 건물 기준 방향을 나타내지 않는다. 각도는 degree 단위이며 센서별 scan 평면 안에서 정의된다.

적재 공간의 평면 원점은 경계 꼭짓점 `(0, 0)`이다. 바닥은 `z = 0`이고 적재 모델과 외벽의 상한은 `z = 10`이다. `top_z_m`은 닫힌 천장면이 아니라 유효 공간과 적재 높이의 상한이다.

## 적재 공간

`boundary_xy_m`은 위에서 내려다본 적재 공간의 닫힌 경계를 나타낸다. 다음 6개 꼭짓점을 반시계 방향으로 연결하고 마지막 꼭짓점에서 첫 꼭짓점으로 돌아간다.

| 순서 | x | y |
| --- | ---: | ---: |
| 0 | 0 | 0 |
| 1 | 4 | 0 |
| 2 | 4 | 5.3 |
| 3 | 2.7 | 5.3 |
| 4 | 1.9 | 2.5 |
| 5 | 0 | 2.5 |

따라서 단일 너비와 길이의 직사각형이 아니라 한쪽 상부 경계가 좁아지는 오목한 6각형이다. 전체 좌표 범위는 x축 0m부터 4m, y축 0m부터 5.3m이고, 꼭짓점에 shoelace 공식을 적용한 바닥 면적은 14.76m2다. 외벽은 각 경계 선분을 `z = 0`부터 `z = 10`까지 수직으로 올린 면이다.

높이 계산 프로세스는 단순한 `width`와 `length` 값으로 공간을 다시 만들지 않는다. `boundary_xy_m`의 꼭짓점을 그대로 사용해 점의 경계 포함 여부와 높이 결과의 유효 영역을 결정한다.

## 센서 배치

센서 자세는 원점 `p0_m`, 0도 광선 단위벡터 `u0`, 90도 광선 단위벡터 `u90`의 세 값으로 정의한다. 두 방향벡터는 서로 직교하고 각 벡터의 길이는 1이다.

| Sensor | 원점 `p0_m` | 0도 바닥 목표점 | `u90` 방향 |
| --- | --- | --- | --- |
| `lidar_1` | `[0.5, 2.5, 10]` | `[0.5, 0.2, 0]` | x축 음의 방향 |
| `lidar_2` | `[2.3, 3.9, 10]` | `[3.8, 3.9, 0]` | y축 음의 방향 |

`u0`은 센서 원점에서 표의 0도 바닥 목표점으로 향하는 벡터를 정규화한 결과다.

```text
u0 = (target - p0_m) / length(target - p0_m)
```

`lidar_1`의 원시 방향벡터는 `[0, -2.3, -10]`이고 `lidar_2`의 원시 방향벡터는 `[1.5, 0, -10]`이다. 정규화한 정확한 값과 각 센서의 `u90` 값은 `v1/fixtures/environment.v1.json`에 있다.

scan의 각 측정점은 다음 식으로 센서별 광선 방향과 3차원 위치를 얻는다.

```text
angle_rad = angle_deg * pi / 180
direction = cos(angle_rad) * u0 + sin(angle_rad) * u90
point = p0_m + distance_m * direction
```

센서별 scan 평면은 `u0`과 `u90`이 만드는 평면이다. 180도 방향은 `-u0`, 270도 방향은 `-u90`이다. 높이 계산 프로세스는 센서 원점이나 자세를 추정하지 않고 환경 설정의 값을 사용한다.

## 생성된 거리의 의미

생성기는 각 광선을 센서 위치에서 발사하고 정적 바닥, 외벽과 현재 적재 표면 중 광선 진행 방향에서 가장 먼저 만나는 면까지의 거리를 만든다. 유효 거리로부터 복원한 점은 바닥, 외벽 또는 현재 적재 표면에 놓일 수 있다. 광선이 유효 측정 대상을 만나지 못하거나 합성 왜곡이 무효 측정을 만들면 `distance_m`은 0이다.

투입구 위치, 적재와 수거 시간, 표면 변화와 측정 왜곡은 scan을 만드는 producer 시나리오의 입력이다. 높이 계산 프로세스는 이미 관측된 거리로 공간점을 복원하므로 이 값을 입력 계약으로 요구하지 않는다. 해당 producer 입력의 정본은 Source Repository의 `examples/generator.v1.json`이다.
